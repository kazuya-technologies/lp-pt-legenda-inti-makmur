# Corporate Landing Page - PT Legenda Inti Makmur 🏢✨

> **Status Proyek:** Produksi / Live  
> **Tautan Web:** [Kunjungi Website Klien](https://legendaintimakmur.com) </br>
> **Kategori:** Produsen Alat Kebersihan & Perabotan Plastik  

Ini adalah repositori resmi untuk pengembangan *landing page* korporat **PT Legenda Inti Makmur**. Proyek ini dirancang dari nol menggunakan kode murni untuk menggantikan arsitektur web lama yang lambat, berantakan di perangkat seluler, serta kurang optimal dalam menjaring mitra bisnis baru.

---

### 🎯 Dampak & Solusi Bisnis

*   **Masalah Klien Sebelum Dialihkan:** Katalog produk alat kebersihan yang sangat banyak membuat *loading* halaman lambat. Akibatnya, calon mitra agen/distributor kabur ke kompetitor sebelum melihat penawaran, serta tombol *Call to Action* (CTA) ke tim *sales* tidak terstruktur dengan baik.
*   **Solusi Kazuya Technologies:** Kami menerapkan arsitektur *Mobile-First Design* dan optimasi aset statis. Hasilnya, katalog produk tampil rapi tanpa memperlambat pemuatan halaman. Kami juga menyematkan tombol WhatsApp CTA strategis yang secara instan meningkatkan konversi prospek kemitraan baru.

### 🛠️ Keunggulan Teknologi & Fitur Utama

*   **Astro + Tailwind CSS:** Menghasilkan halaman HTML statis super ringan tanpa *bloated JavaScript* di sisi pengguna.
*   **Optimasi Gambar Tingkat Lanjut:** Konversi otomatis seluruh aset katalog produk ke format `.webp` yang responsif sesuai resolusi layar perangkat konsumen.
*   **Copywriting Terstruktur:** Penataan teks informasi produk menggunakan pola psikologi penjualan untuk meyakinkan calon distributor besar secara profesional.
*   **SEO-Ready Blueprint:** Struktur kode semantik yang ramah terhadap mesin pencari (*Google Crawlers*) demi visibilitas jangka panjang.

### ⚙️ Struktur Repositori & Pengembangan Lokalan

Jika Anda adalah pengembang dari pihak internal klien atau tim teknis yang ingin meninjau struktur arsitektur kami:

```bash
├── public # Logo, Ikon, Gambar statis teroptimasi
└── src
    ├── assets # Aset statis ( Gambar produk , Video Teroptimasi)
    │   ├── produk # Komponen UI modular (Navbar, Footer, CTA, Card)
    │   └── video_testi 
    ├── components
    │   └── ui
    ├── config
    ├── content
    ├── layouts
    ├── pages
    ├── section
    └── styles
```

#### Cara Menjalankan secara Lokal:

1. Klon repositori ini:
   ```bash
   git clone https://github.com
   ```
2. Masuk ke direktori proyek dan instal dependensi:
   ```bash
   cd lp-pt-legenda-inti-makmur && npm install
   ```
3. Jalankan server pengembangan lokal:
   ```bash
   npm run dev
   ```
